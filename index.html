Benefits Assistant RAG demo · answers only from the sample booklet, with citations

Every answer is logged with the retrieved sections, scores, provider, attempts, validation notes, token estimate and latency, so automated outputs can be traced and reviewed.

Runs the evaluation sets in your browser with the current model. The held-out set was written after tuning and never used to change the rules.

Offline mode (default) picks the best-matching sentences from the retrieved sections: free, instant and deterministic.

To try a real LLM, paste an Anthropic API key. It is kept in memory only (never stored or sent anywhere except api.anthropic.com) and cleared when you close the tab. In production the key stays on the server (see server/).
